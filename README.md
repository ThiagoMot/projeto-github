# Sistema de Biblioteca

Sistema simples em terminal desenvolvido em Python para controle e gerenciamento de acervo bibliotecário.

## Funcionalidades
1. Cadastro de Usuários
2. Cadastro de Livros
3. Empréstimo de Livros (com validação de disponibilidade)
4. Devolução de Livros
5. Listagem de Livros

## Pré-requisitos
* Python 3.10 ou superior instalado

## Como Executar
Execute o comando no terminal na raiz do projeto:
```bash
python atv.py
